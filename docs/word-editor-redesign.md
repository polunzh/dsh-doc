# Word 级单栏富文本编辑器重构设计与实施计划

## 1. 目标与背景
用户要求彻底重建编辑界面，将原有的“左侧 textarea 纯文本 + 右侧常驻预览”双栏架构，升级为类似 Microsoft Word 的单栏沉浸式富文本编辑体验：
1. **取消常驻预览框**：书写过程中不再持续向后端发起 Chrome 渲染，改为按需查看（点击“打印预览”弹窗）。
2. **Word 式 A4 纸张视图**：书写区域直接呈现为标准的 A4 物理纸张（210mm × 297mm），具有真实的纸面背景、投影、页边距内衬与分页表现。
3. **格式功能区（Ribbon 工具栏）**：集成段落样式、粗体、斜体、下划线、对齐、列表、字体、字号、行距、边距及分栏，支持即点即显。
4. **零依赖原生架构**：使用轻量高效的原生 `contenteditable` 与 Selection 引擎，不引入外部打包依赖，与 DSH 插件宿主环境无缝兼容。

## 2. 界面与功能设计
- **顶部工具栏（Word Ribbon）**：
  - 模板选择区：内置通用讲义、自定义模板快速切换。
  - 文本格式群：段落类型（正文 / H1 / H2 / H3 / 引用）、**B** (加粗)、*I* (斜体)、<u>U</u> (下划线)、~~S~~ (删除线)。
  - 对齐群：左对齐、居中、右对齐。
  - 列表群：项目符号列表 (•)、编号列表 (1.)。
  - 版式群：字体下拉选择、字号 Stepper、行距 Stepper、边距 Stepper、单/双栏切换。
- **书写台（The Desk & A4 Paper）**：
  - 居中放置 210mm 宽的真实纸张，纸面具备真实打印页边距，支持跟随窗口宽度等比缩放。
  - 所见即所得排版：字号、行距、字体、分栏实时反应在纸张正文上。
  - 支持键盘快捷键：`Cmd+B`、`Cmd+I`、`Cmd+U`、`Cmd+Z`、`Cmd+Shift+Z`，以及 `Cmd+Enter` 调出打印预览。
- **按需预览与真实出纸**：
  - 底部操作条保留用纸规格（如 A4、长边翻页、用纸张数）、就绪状态指示器。
  - 点击【打印预览】：呼出全屏高清校样模态窗，展示 Chromium 真实渲染分页图及规则校验。
  - 点击【打印】：自动完成最新版式校验并提交局域网打印机出纸。

## 3. 实施计划
1. 清理 `package.json` 中的临时外部依赖，保证插件零打包、即开即用。
2. 在 `lib/client.js` 中构建原生 Word 式富文本编辑组件与 Ribbon 工具栏。
3. 实现富文本内容与后端打印 Markdown/HTML 的双向解析转换器。
4. 完善多语言词典（中/英/日）与样式表，适配深浅主题。
5. 执行自动化测试与离屏截图，验证编辑与预览效果。
